# @tdl/theme-mitchell

Визуальная тема **Mitchell** для игры The Dead Lords — ландшафтный скандинавский/Nordic SLG-интерфейс.

Пакет содержит палитру, глобальные CSS-токены и весь React-рендер HUD.
Ядро (`@tdl/kernel`, `@tdl/host`, `@tdl/protocol`) остаётся нетронутым —
клиент всего лишь импортирует компонент `<MitchellHud/>` и передаёт ему
собранную на стороне клиента ViewModel.

## Подключение на клиенте

```tsx
// apps/client/src/main.tsx
import "@tdl/theme-mitchell/styles"; // палитра + токены + глобальные стили

// apps/client/src/ui/Hud.tsx (тонкий адаптер)
import { MitchellHud } from "@tdl/theme-mitchell/hud";
return <MitchellHud model={viewModel}>{/* модалы клиента */}</MitchellHud>;
```

## Категории UI-элементов Mitchell

Чёткое разделение (чтобы не перепутать, что всегда видно, а что должно появляться
только по событию):

| Категория | Описание | Примеры |
|-----------|----------|---------|
| **А. Постоянный хром** | Всегда на экране. Скелет интерфейса. | Топбар, аватар лорда, ресурсы, часы, левая колонка действий, компас, мини-чат, щитовая навигация, быстрые круглые кнопки. |
| **Б. Кнопки с бейджами** | Кнопка всегда видна; **значок-бейдж** появляется только когда есть непрочитанное/завершённое/доступное. | Стройка (7), Герои (2), Почта (19), Предметы (19), События (4), Помощь (2), Собрать (7), Клан (11). Если `badge.kind === "none"` — бейдж не рендерится. |
| **В. Эвент-элементы** | **Скрыты по умолчанию**. Появляются с анимацией только при наличии данных о событии. | Пузыри на сцене: «Собрать ресурсы» над фермой, «Закончить тренировку», «Ускорить стройку», «Вас атакуют!» (пульсирует), «Помощь клана». Если массив `bubbles` пуст — слой не рендерится. |
| **Г. Условные панели** | Рендерятся только при наличии данных; могут сворачиваться. | Ивентовый баннер `eventBanner` (нет ивента — нет баннера); очереди стройки/тренировки/исследования (пустой массив → блок не выводится); слоты маршей (пустые — тусклые и disabled); квестовая панель (если не передана — не рендерится). |

## Адаптивный масштаб (ландшафт only)

Митчелл — строго горизонтальный интерфейс. Для этого:

- Все размеры (кроме мелких деталей) заданы через CSS-кастомные свойства на базе `vmin`:

  ```css
  --mt-unit: clamp(5px, 0.78vmin, 8px);       /* базовый юнит */
  --mt-topbar-h: calc(var(--mt-unit) * 8);    /* высота топбара */
  --mt-btn-md:   calc(var(--mt-unit) * 8.5);  /* крупная кнопка */
  --mt-fs-md:    calc(var(--mt-unit) * 2.3);  /* основной кегль */
  /* …и т.д. */
  ```

  При разрешении 768px по высоте `1vmin ≈ 7.68px` → `--mt-unit ≈ 6px`.
  При 1440px — `1vmin ≈ 14.4px`, но `clamp()` зажимает юнит до `8px`, чтобы
  элементы не раздувались на 4К. Минимально возможная высота — ~640px.
- Safe-area-инсеты учтены: `--mt-safe-b/t/l/r` завязаны на `env(safe-area-inset-*)`.
- Вертикальная ориентация на узких экранах (<=1000px ширины в портрете) **блокируется**
  экраном `PortraitGuard` с просьбой повернуть устройство. На ландшафтных мониторах
  этот экран не показывается никогда.
- Дополнительное медиа `@media (max-width: 1100px)` чуть уплотняет отступы
  ресурсов и левой колонки на нетбуках/оконном режиме.

## Как добавить новую зону

1. Создайте `MyZone.tsx` и `MyZone.module.css` в `src/hud/components/`.
2. Компонент принимает строго описанные пропсы и не обращается к глобальному
   состоянию напрямую. Для бейджей используйте现成的 `<Badge badge={...}/>`.
3. Если зона условная — пусть при отсутствии данных возвращает `null`.
4. Добавьте поле в `HudMitchellViewModel` (в `types.ts`).
5. Вставьте компонент в разметку `MitchellHud.tsx` в нужном месте относительно
   других зон. Слои: сцена=0, bubbles=10, панели=20, ивентовый баннер=25,
   компас/щит-навигация=25, топбар=30, подсказка=35, модалы=40+.
6. Обновите этот README в разделе «Архитектура».

## Соглашения

- Имена CSS-классов модульные (через `.module.css`), не полагаются на глобальные
  селекторы. Глобальные классы начинаются с префикса `mt-` (например,
  `.mt-portrait-guard`, `@keyframes mt-spin`), чтобы не конфликтовать с
  другими темами при горячей смене.
- Эмодзи как иконки — временная мера на стадии каркаса. На шаге «Иконки» плана
  они будут заменены на собственные SVG в скандинавском стиле.
- Форматирование чисел (`fmt`) и часов (`utcNow`) живёт в клиентском адаптере,
  а не в теме — тема получает уже готовые строки/числа.
- Тема **не импортирует** `@tdl/protocol`, `@tdl/kernel`, стор или роутер.
  Все колбэки передаются как простые функции через пропсы. Это делает тему
  полностью свопабельной одним импортом.
