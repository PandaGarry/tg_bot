# THE BETWEEN — Art Benchmark 01

An original, code-authored SVG asset study for the first grounded frontier-fantasy environment direction. No paid packs and no generated concept image are used in this set.

## Included source assets
- ground-clearing.svg — organic terrain clearing with restrained surface variation.
- oak-tree.svg — layered broadleaf tree with shared foliage and bark language.
- frontier-house.svg — timber-and-plaster frontier dwelling.
- stone-well.svg — stone well with timber lifting frame.
- wood-fence.svg — modular fence segment.
- fieldstone.svg — ground stone prop.
- traveler.svg — first scale/proportion placeholder character.

## Art direction v0.1
- Mood: inhabited frontier, quiet, weathered, grounded; avoid toy-like shapes and high-saturation fantasy candy colors.
- Palette: moss/lichen greens, warm limestone and plaster, smoked timber, muted blue-green glass, restrained ochre highlights.
- Light: warm upper-left key light, cool green ambient fill, soft contact shadows.
- Materials: layered color planes and sparse material marks; no heavy black outlines, no noisy micro-detail.
- Silhouette: readable at gameplay scale; irregular natural edges, sturdy construction, restrained ornament.
- Perspective: oblique/isometric-inspired composition, consistent ground contact and scale.

## Limitations
This is a first visual consistency probe, not a final production pack. Assets are hand-authored vector source files, not painterly raster illustrations. The traveler is a proportion placeholder, not animation-ready. The composition page is a browser preview, not a Godot runtime capture. Next gate: judge the full set together, revise the style, then establish the engine import pipeline.
