# Эшфолл · Пепел Второго Света

MVP мобильной стратегии в духе **Rise of Kingdoms / Game of Thrones: Conquest**: королевства,
город с постройками, армия, марши по карте с ETA, мгновенный бой, донесения разведки и
межкоролевская карта **KvK** с жар-колодцами.

Клиент — обычное **mobile-first веб-приложение** (открывается в браузере телефона, портретная
ориентация). Telegram Mini App из плана убран: цель — игра, которая потом собирается в натив
через Capacitor/Cocos, а не встраивается в мессенджер.

```
npm install
npm run build     # собрать клиента
npm start         # http://localhost:8787  (сервер отдаёт и API, и статику)
```

Для разработки: `npm run dev` — Vite на `:5173` с прокси на сервер `:8787`.

## Стек и почему именно он

| Слой | Выбор | Причина |
|---|---|---|
| Язык | **TypeScript везде** | один язык на клиент, сервер и тесты — главный множитель скорости для соло-разработки |
| Правила игры | `packages/rules` — чистые функции | формулы, бой, тайминги маршей покрыты тестами и работают и на сервере, и на клиенте (предпросмотр ETA/грузоподъёмности) |
| Сервер | **Node 22 + `node:sqlite`** | ноль инфраструктуры: без Redis, без Postgres, без нативных зависимостей. Один процесс — один писатель на мир |
| Realtime | WebSocket + дифф-патчи по миру | клиент получает только изменившиеся сущности карты |
| Клиент | **Vite + Canvas 2D**, без игрового движка | 47 КБ JS, мгновенная загрузка на телефоне, полный контроль над картой; движок (Cocos/Capacitor) подключается позже, игра от этого не зависит |

Исследование альтернатив (SpacetimeDB, Nakama, Colyseus, Agones, slgserver, TravianZ, BitCraft,
Metaplay и др.) — в [docs/research/2026-09-24-stack-research.md](docs/research/2026-09-24-stack-research.md).

## Архитектура (заложена под KvK с первого дня)

```
packages/rules     чистые правила: экономика, бой, карта, тайминги маршей (vitest, 21 тест)
packages/shared    контракт клиент↔сервер: view-модели и сообщения
apps/server        симуляция мира + HTTP/WS + раздача статики
apps/client        mobile-first UI: канвас карты, шторки, панели
scripts/           смоук-тесты игрового цикла, KvK и интерфейса
```

Пять решений, которые держат архитектуру:

1. **`world_id` на каждой сущности.** Королевство и KvK-карта — один и тот же код. Переселение
   города = одна транзакция (`UPDATE players SET world_id …`), а не миграция между серверами.
2. **Один писатель на мир.** Никаких распределённых блокировок: вся логика — редьюсеры в одном
   процессе. Горизонтальное масштабирование — по числу миров.
3. **Время вместо тиков.** Марш — это пара `(depart_at, arrive_at)`; ресурсы считаются лениво по
   прошедшему времени; тик (500 мс) разбирает только наступившие события. 5 000 городов не
   требуют 5 000 таймеров.
4. **Карта не хранится в базе.** 9 216 тайлов выводятся из seed'а детерминированным шумом и
   уезжают на клиент одним base64-блобом (~12 КБ). В базе — только сущности.
5. **Бой мгновенный.** Армия дошла — бой посчитан и записан в отчёт. Это дешевле в 100 раз, чем
   реалтайм-поле боя, и даёт ту же глубину (контр-юниты, стена, дом, случайность).

## Тесты

```bash
npm test          # 21 юнит-тест правил: экономика, бой, карта, тайминги
npm run smoke     # цикл через WebSocket: регистрация → город → стройка → обучение → марш → бой
npm run smoke:kvk # переселение в KvK, захват жар-колодца, начисление Жара, рейтинг
npm run smoke:ui  # интерфейс целиком в jsdom: вход, выбор места, панели, марш, отчёты
```

Смоук-тестам нужен запущенный сервер (`npm start`).

### Живые скриншоты

```bash
npm start                      # в одном терминале
npm run shots                  # снимает 18 экранов телефона (390×844) в ./shots
npm run montage shots/лист.png 4 220 shots/*.png   # склеивает кадры в один лист
```

В песочнице внешние CDN закрыты, поэтому браузер ставится из npm-пакета
`@sparticuz/chromium` (в нём лежит сам Chromium и нужные системные библиотеки) —
в обычной среде хватит `npx playwright install chromium`. Скрипт проходит весь путь сам:
вход → основание города → постройки → войско → марш на лагерь → переселение в KvK →
захват жар-колодца → боевой отчёт.

## Что намеренно не сделано в MVP

- Альянсы, чат, марши в несколько волн, осада столицы.
- Наступательный ИИ: боты растут и защищаются, но не атакуют первыми.
- Fog of war (туман войны): разведка приносит донесение, но карта открыта.
- Платежи, ускорения за валюту, пуши, сезонный ресет KvK.
- Реальная аутентификация: вход по имени (токен в localStorage).

## Следующий шаг

Спайк перед продакшеном: карта 1 200×1 200 чанками, 5 000 городов, 500 ботов-нагрузчиков,
замеры памяти и латентности патчей. Если упрёмся в SQLite — следующим шагом замена `db.ts` на
Postgres без переписывания `packages/rules`, потому что правила от базы не зависят.
