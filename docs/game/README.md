# Мёртвые лорды

Имя игры. В английском интерфейсе: **The Dead Lords**, коротко **TDL**.

Полная история — [01-lore.md](01-lore.md). Если рассказ расходится с другим файлом, верна она. Числа и сроки — в системах.

Игрок — зомби-лорд одного замка. Половина людей жива. Столица даёт клану неделю, не конец света.

Отдельного имени у страны нет. Страна не кнопка, не фракция и не объект карты. Есть земля, столица, яма, замки и кланы.

Меняется стиль. Механики сначала классические. Своя изюминка — после фундамента.

Пример Эшфолл из репозитория удалён. Он не является базой.

## Уже решено

- Имя игры: Мёртвые лорды / The Dead Lords (TDL). Не Lords of the Dead: это другая сторона. Имени страны нет.
- Мать — грибница. Она не ходит. Ходят заражённые, пока у них один разум.
- Мать убита. Поэтому у лордов свой ум. Грибы с ней не разговаривают.
- Ферма растит грибы. Грибы кормят только исследования и навыки лорда.
- Загон растит мясо. На карте стада. Победа над живым тоже даёт мясо, тот же ресурс.
- Замку нужны мясо, древесина, камень, металл.
- Марш ведёт командир. У командиров грейды и навыки.
- У лорда три ветки навыков. У исследований три ветки: фарм, атака, скорость стройки.
- Дом игрока — замок. Отдельной игры за одиночку нет.
- Создание лорда: имя, портрет, знамя, тип. Не конструктор лица.
- Столица в центре. Семь дней преимущества клану, затем город сам нейтральный, три дня кланы его не бьют, потом можно брать снова.
- Половина населения жива по всей земле, не только в столице.
- Ирония в голосе хрониста. Не в имени ресурса и не в кнопке.
- Своя изюминка не входит в фундамент. Кандидаты записаны в плане и не разрабатываются сейчас.
- Русский и английский с первого текста.
