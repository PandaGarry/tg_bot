## A. «Пузырь в сцене» — объяснение (на скринах заказчика)

Это **твой же скрин IMG_5602 / IMG_5605**. В Viking Rise прогресс очереди не живёт только
в HUD-панели — он **приклеен к зданию в самой сцене** маленьким чёрным «пилюлей»:

```
    [ иконка | 00:28:53 | >> ]   <- пилюля под зданием: что строится, сколько осталось,
    [ домик/мельница/казарма ]      кнопка ускорения (расходует предмет)
```

Несколько очередей одновременно — у каждой своя пилюля (IMG_5605: 12:11:09, 10:43:31,
10:43:28, 06:37:24, 00:28:27…). Цвет/иконка показывает тип: зелёная = производство,
книжка = обучение, свиток = стройка. Плюс **крестик-пилюли над зданиями** (IMG_5598/5596) —
круглые иконки-действия: что сейчас можно сделать с этим зданием (улучшить, произвести,
нанимать). И ещё — «речевые пузыри» событий в сцене (например, «Таинственный шлем»).

Т.е. схема VR: **взгляд** — сцена (пилюля на здании), **деталь** — панель в HUD
(список очередей, ускорение, отмена). Предложение: делаем так же (Pixi-пилюля + HUD-панель).

## B. Разбор 16 реальных экранов

### B1. Двор — главный экран (IMG_5598, 5596, 5602, 5605, 5609)

Пять кадров одного экрана в разных состояниях:

- **Сверху-слева: карточка лорда** — портрет, ⚔ сила (2 512 262), уровень (6), стрелка,
  красная точка (непрочитанное). Главный статус — всегда под рукой, не в меню.
- **Слева, под ней: главная линия «Глава 31, 7/7»** — прогресс главы + **карточки наград**
  (50K, 500K, гемы, 400/400/39,0K) прямо в панели. Видна всегда, на любом экране двора.
- **Сверху-справа: ресурсная полоса** (население 0/18, 🥩 3.1M, 🪵 2.7M, 🪨 2.4M, 💰 2.4M,
  💎 66, «+») и часы UTC. **Под ней — ряд баннеров событий с таймерами**
  («Возвращение короля» 9 дн., «Быстрое развитие VS» 05:47:59, «Снабж. самоцетами» New,
  «Центр событий» New).
- **В сцене: пузыри над зданиями** — круглые иконки доступных действий
  (молот = улучшить, мешок = ресурс, книга = обучить, лук/меч = военное, монета = декор).
  Разные кадры — разные иконки: пузыри показывают *состояние* здания.
- **Стройка/производство = пилюли** (см. раздел A).
- **Режим имён** (IMG_5609): на каждом здании название + уровень в шестиугольнике
  («Зал вождя 20», «Таверна меда 17», «Казармы грузчиков 13») — включается/выключается.
- **Выбранное здание** (IMG_5629): название крупно + **4 круглые кнопки действий**
  (ℹ инфо, ↑ улучшить, >> ускорить, ⚓ произвести).
- **Снизу-слева: компас** (вход на карту) + 4 кнопки-инструмента (молот, портреты, свиток)
  + **чат-фид** (99+ сообщений племени).
- **Снизу-справа: нижний док** — 4–5 кнопок с бейджами (2, 99+) + звёздная кнопка выше
  (награда/профиль) + «плюс-сетка» (все системы).

### B2. Стройка и декор (IMG_5600, 5599)

- Навигация слева: **Внутренние дела / Военные / Декор**; вкладки (Основное / Атмосфера / Особое).
- **Горизонтальная 3D-карусель карточек**: спрайт здания на плитке, название, описание
  («Исследуйте новые технологии здесь»), стоимость (🪵 2 000), «Время: 0 сек.»,
  **«Построен: 0/100»** — лимит количества; состояние максимума — «Вы не можете больше
  строить такое здание».
- **Декор — полноценная система**: Факел («Пламя, освещающее темную ночь»), Факел Дреки,
  Красный клён, Белая берёза, Зимнее дерево — с лимитами. Двор украшают, и это *играбельно*.

### B3. Предметы/инвентарь (IMG_5619, 5620)

- Слева: **колонка категорий с бейджами** (Ресурсы 44, Ускорение 38, Полож. эффекты 11,
  Снаряжение 99+, Транспорт 97, Драгоценность 5, Другие 91).
- Центр: **сетка предметов с рамками по редкости** (зелёный/синий/фиолет/золото) и счётчиками.
- Справа: панель предмета — иконка, описание («Даёт 1000 еды, 1000 дерева или 800 камня»),
  выбор количества (1 / + / MAX), «В наличии: 14», кнопка **«Исп.»**.
- Вкладка «Ускорение»: сетка пилюль ускорения по длительности (1 мин ×724 … 24 ч ×3) —
  то, что жмут в пилюлях сцены (раздел A).

### B4. Герои (IMG_5623)

- Сетка карточек: рамка = редкость, **уровень (40/32/28/14/3/3)**, звёзды, иконка класса,
  бейдж «назначен в войско» (зелёный щиток).
- Справа: **большой рендер** героя + класс («Ходок») + имя (РОЛЛО) + ⚔ 71 211 +
  **теги: Пехота / PvP / Боевая атака**. Сверху: фильтр «Класс», счётчик 22, «Детали».

### B5. Создание войска (IMG_5606)

- Слева: **выбор главного командира** (сетка, «Рекомендуется 21 ур.»).
- Центр: **два слота** (Главный командир Ролло + Второстепенный Айвор) с кольцами скиллов,
  питомец (медведь, 10), буффы внизу (0%, XP +1,5%, «Больше»).
- Справа: **состав по тирам** (Воин с топором T4 — 310, Крикун T3 — 49 699, Боец T2 — 7 938,
  T1 — 4 063) со **слайдерами количества**; «Всего силы: 439 073», «Войска: 83 555/83 555»,
  «Энергия: 50», «Тяжёлая битва», «Очистить» / **«Марш 00:00:06»** / «Множество».

### B6. Карта мира (IMG_5607, 5608)

- Сверху: **координаты «#367 X: 787 Y: 243» + поиск**; армия, события с таймерами.
- По карте: армии со счётчиками (5/14/47/11/20), **пунктирный маршрут + дистанция «8км»**,
  босс-узлы (яйцо дракона), города с именами, **аллианс-полосы** (зелёные линии территорий).
- **Нижний док меняется по контексту**: на карте — военные кнопки (мечи, шлем/войска,
  рюкзак, якорь, щит), на дворе — городские (книга, рукопожатие, документы, почта).

### B7. Управление городом (IMG_5630)

- Секция «Перемещение»: **Конкретное** (переместить в выбранное место; нельзя, пока
  воюют войска сбора) / **Шанс бесплатного** (каждые 3 дня ×1, не более 2; только после вступления
  в племя) / **Случайное**; секция «Сезон».

### B8. Профиль вождя (IMG_5597)

- 3D-образ вождя + навигация (Лич. инфо / Больше инфо / Рейтинг / Настройки).
- Панель: имя, ID, 👍 0, **XP-полоса 1000/1000 + «+»**, племя #367, **Сила 2 512 262**,
  Очки убийств 1 050 527, Уровень коллекционера 4, Уровень острова мечты (Заблокировано).
- **«Колесо навыков» — шестиугольники 1–5** (New, замок) — прокачка профиля.

## D. Скелет главного экрана «Двор» (первая версия для выбора)

```
┌──────────────────────────────────────────────────────────────────────┐
│ [👤 6] [ «Путь вождя» 2/5 ▸🥩50K🪵50K💎1 ]        [0/18 🥩🪵🪨💰💎 +] [UTC]│  топ (зона A)
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│        ┌────────────────────────────────────────────┐                │
│        │        PIXI-СЦЕНА: двор 14×14              │                │
│        │  сетка • здания (имена+уровни: вкл/выкл)   │   зона B      │
│        │  [иконка|00:28:53|>>]  пилюли на зданиях   │  (canvas)     │
│        │  выбор → ℹ ↑ >> ⚓ круглые кнопки          │                │
│        └────────────────────────────────────────────┘                │
│                                                                      │
│ [🧭] [🔨] [📜]                       [⚔][🏠][👥][🛡][☰] (бейджи)     │  низ (зона C)
└──────────────────────────────────────────────────────────────────────┘
```

Зоны и их содержимое (стартовый состав, 6–8 элементов):

- **A-топ.** Слева: карточка вождя (иконка + уровень + красная точка). Центр:
  главная линия «Путь вождя x/y» + 2–3 наградки (тап — детали главы). Справа:
  ресурсная полоса (уже есть в hud.css) + «+».
- **B-сцена.** Pixi: диметрическая сетка 14×14, здания по серверному виду,
  пилюли очередей, режим имён, выбор здания → 4 круглые кнопки.
- **C-низ.** Слева: компас («Мир», до этапа 5 — заглушка), инструменты.
  Справа: **док из 5**: Поход (⚔), Двор (🏠), Герои (👥), Альянс (🛡), Меню (☰) + бейджи.
- **Панели-детали** (открываются поверх, не в скелете): очередь/улучшения (пилюли —
  деталь), «Строить» (карусель, паттерн 10), профиль.

**Отличия от текущего hud.css:** нет карточки вождя (есть только ресурсы), нет главной
линии, нет дока-контекста, нет пилюль в сцене. Остальное (полоса ресурсов, кнопки) — уже есть.

## E. Открытые вопросы (до выбора вариантов)

1. **(к вопросу 3)** Стройка: делаем **оба** — пилюля в сцене (взгляд) + панель в HUD
   (деталь/ускорение), как в VR? Да/нет.
2. **Содержание главной линии**: ядро пока знает только «Двор». Предложение на старт —
   4 шага, каждый — реальная команда ядра: «Основать двор» (готово) → «Построить первое
   здание» → «Построить второе» → «Улучшить здание до 2 ур.»? Или свои формулировки?
3. **Декор** (паттерн 11): берём? (Факелы/деревья на сетке с лимитом — дают дворцу
   «живость» и почти ничего не стоят на сетке 14×14.)
4. **Варианты**: следующий шаг этапа 2.5 — 3–5 вариантов этого скелета на CSS
   (макеты, как `ui/hud/main-screen.html`) + выбор. Палитра: «кость-дерево №05»
   (тёплые дерево/кость, наш стиль) — подтверждаем?
