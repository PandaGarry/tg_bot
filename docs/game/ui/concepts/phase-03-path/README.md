# Этап 3 — тропинка и подъезд (концепт на согласование)

Замечание заказчика (01.10.2026): подъезд к воротам «квадратный» и обрывается; тропинка игрока похожа на
клумбу. Нужна узкая, слегка украшенная тропинка, а подъезд должен уходить за край экрана.

Концепты (ИИ-правка поверх скриншотов игры, это ориентир, а не текстуры сцены):
- `path-yard.jpg` — узкая извилистая тропа от крыльца к воротам: утоптанный светлый грунт, мягкие края,
  плоские камни со снегом по бокам, фонарик у крыльца, колышки с верёвкой.
- `path-gate.jpg` — дорога за воротами: колея, топтаный снег по обочинам, камни и колышки, плавный изгиб,
  уход за нижний край кадра; внутри ворот тропа продолжается.

Ориентиры из других игр (не копируются): карты мобильных стратегий и ферм ведут дороги узкими плавными
линиями с мягкой кромкой, а не плитками; снег и камни по краям связывают дорогу с окружением.

## План реализации после одобрения
1. Лента вместо плиток: сглаженная кривая (Catmull-Rom) через центры выложенных клеток, ширина ≈ 0.55 клетки,
   мягкая кромка (затухание по краю), без квадратных границ. Игрок по-прежнему кладёт клетки, внешний вид — наш.
2. Подъезд: та же лента, продолжается за ворота и уходит далеко за край кадра; колея, топтаный снег по обочинам.
3. Украшения: камни со снегом по кромке (уже есть), колышки с верёвкой, фонарик у крыльца и ворот.
