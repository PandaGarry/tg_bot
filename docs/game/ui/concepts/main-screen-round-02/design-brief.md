# Главный экран, круг 2: от Bone-Wood №02 — с мультяшностью, иронией и своими якорями

**Статус:** пять кандидатов на выбор заказчика (26.09.2026). Не утверждённый UI. Надписи и числа внутри
картинок — заглушки генератора; текст в продукте берётся из локализации.

## 1. Ответ на вопросы заказчика

**Стиль — только набросок?** Да. Ни один skin не утверждён ([06-plan.md](../../../06-plan.md), этап 4b открыт).
Картинка `bone-wood-main-screen/01-main-screen-idle.jpg` была доработкой варианта №08 из round-05, а не
развитием **Bone-Wood №02** (`lore-reset/02-bone-wood-bright-hud.jpg`), который заказчик назвал отправной точкой.
Ошибка наша: №02 сохранили как «стилевой якорь» в тексте, а генерации вели от другого кадра.

**Соответствует ли прежний кадр стандартам жанра?** Скелет — частично, лицо игры — нет. Сверка по
[17-ui.md §13.5](../../../17-ui.md) (общий язык жанра по Whiteout, Last War, Kingshot, RoK):

| Элемент жанра / TDL | Прежний кадр | Круг 2 |
|---|---|---|
| Портрет лорда слева, уровень, опыт | есть | есть, лорд **мёртвый** (бледное спокойное лицо) |
| Пять ресурсов, числа сокращённые | есть, числа полные | есть, `1.5K` / `1.1K` |
| Бейджи внимания над объектами (3–5) | **нет** | зелёный плюс, восклицание, таймер |
| Боковая колонка круглых кнопок (RoK) | **нет** | четыре: письмо, хроника, знамя, события |
| Социальное видно на сцене (флаг/клан) | **нет** | личное знамя двора на шесте и на доме |
| Сезон/время | есть | есть |
| Нижняя навигация из пяти | есть | есть, подписи по-русски |
| Якорь «частокол» ([§10](../../../17-ui.md)) | **нет** — двор без ограды | есть, граница «своё/чужое» |
| Якорь «хроника» | **нет** | лента хрониста над навигацией |
| Якорь «погреб с грибами» | только ячейка HUD | погреб на сцене с корзинами |
| Якорь «знамя двора» | **нет** | знамя с эмблемой (овца) |
| Загон и стадо (мясо — из скота) | **нет** | овцы и две коровы |
| Мёртвые как люди | жители выглядели **живыми** | бледные, спокойные, в своей одежде, заняты делом |
| Ирония в микротексте ([02-tone.md](../../../02-tone.md)) | **нет** | реплики хрониста из канона |
| Мультяшность уровня RoK | полуреалистичные пропорции | крупные формы, толстые снежные шапки, чистая деталь |

Итог: прежний кадр был чистой, но безликой «средневековой стройкой» — без мёртвых, без ограды, без знамени,
без хроники, без шутки. Отсюда ощущение копии.

**Где уникальность.** Три вещи, которых нет ни у одного из 14 разобранных конкурентов:
1. **Мёртвые, которые просто живут.** Бледные люди в шарфах спорят у лесопилки, кормят овец, вешают бельё.
   Это читается на одном экране без подписи — то самое правило якоря.
2. **Хронист.** Одна сухая строка на пергаменте над навигацией. Шутит она, не кнопки и не экран поражения.
3. **Двор как ферма за частоколом, а не крепость-витрина.** Загон, погреб, грядки, бельё — быт, а не парад.

## 2. Что общее у всех пяти

Основа — Bone-Wood №02: костяные вставки в тёмном дереве с гвоздями, светлая зима, двор за частоколом,
плоский HUD поверх объёмной сцены. Слева портрет мёртвого лорда (человеческое лицо, только опыт — без HP,
энергии и маны). Справа пять ячеек: мясо, дерево, камень, металл и отдельно грибы (серые, без свечения).
Три бейджа внимания. Колонка из четырёх круглых кнопок. Лента хрониста. Пять вкладок: Двор · Карта · Марши ·
Клан · Лорд. Только idle-состояние двора — без режима строительства, сетки и открытых окон.

## 4. Известные дефекты генерации (не решения)

- Иконка вкладки «Двор» — молоток, «Лорд» — сумка; в наборе будут дом и портрет.
- Полоса опыта в №01 подписана `ONE`; в остальных — `XP`.
- В №03 бейджи-кляксы крупнее нормы; в №05 под портретом три чужих значка.
- Погреб на всех кадрах стоит за частоколом — место постройки решается свободной планировкой, не картинкой.
- Кадр 16:9 показывает композицию; ориентация и разрешение клиента этим не фиксируются.

## 5. Как выбрать

Ответ для фиксации: `основной №…; запасной №…` и, если нужно, «что взять из других». После выбора рисуется
не новая россыпь, а один набор компонентов в выбранном языке (панель, кнопка, ресурсная ячейка, бейдж,
таймер, вкладка, иконка в трёх размерах) — и уже из него собирается живой макет двора 390×844.
