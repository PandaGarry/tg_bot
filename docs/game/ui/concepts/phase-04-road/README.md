# Этап 4 — дорога за воротами: отдельная текстура

Замечание заказчика (01.10.2026): дорога и тропа во дворе — разные элементы, у них разная текстура; дорога не должна резко отличаться по ширине от двора и должна вернуть «разноцветие» концепта; вместо изгиба — лёгкая обвалка снега по краям.

- `road-texture-sample.jpg` — выбранный образец (2048², песчаные, красно-коричневые и серые пятна, мелкая галька, трещины).
- Игровая копия: `apps/client/public/textures/winter/road.jpg` (1536², бесшовная — собрана зеркалированием образца).
- Дорога: прямая, шириной с проём ворот (`ROAD_R = GATE_HALF`), одной ширины по всей длине, кромка почти чёткая; по краям низкие снежные валики (`snowBlob`), колея слабая.
- Тропа во дворе: `ground-mud`, светлый песчаный тон, узкая.
