## Урок про three.js
Если у материала `map` появляется после первой компиляции (текстура догрузилась), three.js рисует его белым.
Поэтому материалы с текстурами создаются заново через `key="tex"` / `key="plain"`.

## Снег как объём (`apps/client/src/court/skin/snow.ts`)
Снег везде лежит слоем с мягкой кромкой, а не плоским пятном. Функции для всех зимних скинов:
- `snowBand` — вал вдоль стены внутри двора (высота 0.14–0.45, ширина 0.5–1.6, у ворот и построек сходит на нет);
- `snowBlob` — низкие снежные «языки» и угловые сугробы, кромка уходит под грунт;
- `snowConeCap` — шапка на ярусе ели с рваной нижней кромкой;
- `snowMound` — шапка на бревне и столбе; её же берут крыши зданий, когда мы их введём;
- `snowRidge` — вытянутый вал на балке (перекладина ворот, коньки крыш).
Середина двора остаётся чистой землёй под застройку; снег не лежит на постройках и дорогах (`blocked`).

Снимки двора: `corepack pnpm exec tsx tools/shots/yard.ts` (нужен `bash tools/replit-dev.sh`), результат в `.tmp/`.
