## Выбор заказчика и пять стадий (02.10.2026)

Выбран вариант 3 (костяной зал). Пять стадий развития лежат в `stages/`: `stage-1-lv01-05`, `stage-2-lv06-10`, `stage-3-lv11-15`, `stage-4-lv16-20`, `stage-5-lv21-25`.

Что видно:
- Лесенка читается: хижина → зал с крыльцом и пристройкой → двухэтажный зал → каменная крепость с башней → шпили и рога.
- Общие признаки на всех стадиях: тёмное дерево, рога на коньке, костяные рёбра у входа, резьба. Они и держат узнаваемость.
- Замечания: направление здания и вход меняются между стадиями; стадия 3 уже стадии 2; стадии 4 и 5 занимают почти весь двор в ширину, то есть заметно больше 3×3; на стадии 4 слишком много камня и мало кости.

Следующий шаг: выровнять ось и вход, держать одинаковый футпринт (рост вверх), добавить кость на стадии 1 и 4.
