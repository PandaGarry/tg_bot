Следующий шаг: выровнять ось и вход, держать одинаковый футпринт (рост вверх), добавить кость на стадии 1 и 4.

## Пять стадий v2 — строго на 3×3 (02.10.2026)

Решение заказчика: размер Цитадели фиксирован, 3×3 клетки (3.3×3.3 ед.), рост только вверх и материалом. Иначе здания накладывались бы друг на друга, пока игрок их не переставит.

- `footprint-3x3.jpg` — эталон: чистая сцена с красным контуром 3×3 на месте Ратуши. Снят скриптом `tools/shots/clean.ts` с временной правкой сцены, в игру правка не попала.
- `stages-v2/stage-1…5-*.jpg` — стадии I–V на этом контуре.
- `footprint-check-v2.jpg` — контур 3×3 поверх всех пяти стадий для проверки.

Материалы по стадиям (бедное поселение: начинается с дерева, заканчивается камнем и металлом, декора мало):
1. I (1–5): бревенчатая хижина, одна пара рогов.
2. II (6–10): тёмный деревянный зал, крыльцо, пристройка, костяная арка.
3. III (11–15): двухэтажный деревянный зал на каменном цоколе, рёберная арка, окно в крыше.
4. IV (16–20): каменный первый этаж, деревянный второй, квадратная башня, знамя.
5. V (21–25): серый камень, железные обручи, шпиль, четыре угловые башенки, рёберная арка у ворот.

Замечания: у II основание слегка шире квадрата слева; у V башенки на углах выходят чуть за контур; у I крыша немного свисает. Для 3D это допуск: за основу берём контур 3×3.
