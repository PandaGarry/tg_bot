Ещё 10 вариантов игрового UI

Сравнение одной игровой ситуации: зимний двор, выбрана защитная стена, открыта панель улучшения. Варианты отличаются композицией, формой панелей, контрастом и материалами — это самостоятельные концепты, а не перекраска одного шаблона.

Палитры-ориентиры: концепты № 04, 09 и 10 первой серии. Здесь они используются только как цветовые референсы: ни один стиль не выбран.
Важно: это AI-концепты для сравнения, а не подтверждённые игровые экраны. Мелкие надписи и числа внутри изображений могут быть неточными заглушками. В вариантах 04, 06 и 07 крупные подписи вручную приведены к короткому современному русскому; подписи в галерее описывают только визуальное направление.
