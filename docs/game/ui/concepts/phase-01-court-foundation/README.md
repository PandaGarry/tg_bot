# Этап 1 — основа двора

Концепт `concept-review.jpg` выбран пользователем 01.10.2026 как направление для проработки основы двора. Это художественный ориентир, а не текстура сцены и не runtime-ассет.

## В этой итерации

- открытая площадка из уплотнённой земли с неровной снежной кромкой;
- частокол и простые распахнутые ворота;
- сетка 14×14;
- три низких каменных пятна-фундамента без надземных стен;
- простой грунтовый подход к воротам.

Постройки, башни у ворот, деревья, животные и декор в режиме предпросмотра скрыты. Обычный игровой двор и его данные не меняются.

## Предпросмотр

В development-режиме откройте игру с query-параметром `?court=foundation`. Предпросмотр не отправляет `court.enter` и не меняет сохранённый двор. Уберите параметр, чтобы вернуться в обычный режим.
