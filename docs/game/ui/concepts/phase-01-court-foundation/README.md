# Этап 1 — основа двора

Концепт `concept-review.jpg` одобрен заказчиком 01.10.2026 (с пожеланием: ворота должны быть нормальными и
улучшаться вместе с уровнем). Это художественный ориентир, а не текстура сцены.

Земля с рельефом и снежной кромкой, высокий частокол, подход к воротам, строительная сетка и ворота-арка со
створками (три ступени вида по уровню). Реализовано как скин `bone-wood` — см.
[26-skins-and-hud-plan.md](../../../26-skins-and-hud-plan.md).
