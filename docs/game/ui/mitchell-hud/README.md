# Mitchell — прототип ландшафтного HUD

Изолированный статический HTML/CSS-макет главного экрана для темы Mitchell
(северно-скандинавский стиль). Никак не связан с клиентом/сервером/React,
открывается напрямую в браузере как файл.

## Как смотреть

```bash
cd docs/game/ui/mitchell-hud
python3 -m http.server 8090 --bind 0.0.0.0
```

Или просто открыть `index.html` в браузере.

## Размеры

Прототип рассчитан на ландшафтную ориентацию с соотношением сторон 16:9
(база 1366×768 и 1920×1080). Композиция:

- Верхняя тонкая тёмная полоса (40px): аватар → ресурсы в ряд → часы/настройки
- Слева вверху: квестовая панель, очереди прогресса
- Слева внизу: большая круглая золотая кнопка Компаса (Карта мира)
- Над левым нижним углом (правее компаса): полупрозрачный чат (3 строчки)
- Справа вверху: портреты маршей/разведчиков
- Справа в середине-низу: вертикальная колонка круглых быстрых кнопок
- Правый нижний угол: горизонтальный ряд щитовых (восьмиугольных) кнопок
- Временная тестовая подложка: градиент травы и неба для оценки контраста

## Иконки

На первой итерации иконки отсутствуют — используются универсальные заглушки
(геометрические формы и символы). Реальный набор иконок делается после
утверждения композиции.
