# Двор: разбор HUD в жанре и целевая схема TDL

*Круг 18 (28.09.2026). Основано на разборе 12 скриншотов Rise of Kingdoms ([21-rok-reference.md](21-rok-reference.md),
круг 4) и общих чертах жанра (Lords Mobile, State of Survival, Clash of Clans).*

## 1. Куда что ставит жанр

| Зона | Rise of Kingdoms | Lords Mobile / SoS | Функция |
|---|---|---|---|
| Верх-лево | Губернатор: портрет, кольцо уровня, сила полным числом, VIP, баффы | То же + ник и альянс | «Кто я и чем усилен» |
| Лево | Кнопка заданий-свиток; ниже — молот «Строить» Ø72 и карта Ø84, чат | Молот и очереди процессов | Самые частые действия — под большой палец |
| Верх-право | Ресурсы в одну строку (еда, дерево, камень, золото), камни «+» | Та же строка | Склад: растёт влево, никогда не в два ряда |
| Право | События с таймерами, задания дня, список маршей; ниже — почта со счётчиком | Квест-трекер, магазин, предметы, «ещё» | «Что происходит без меня» + служебное |
| Низ | Панель 4 вкладок: Кампания · Предметы · Альянс · Командир, ☰ сворачивает | Нижняя навигация разделов | Предел — 4–5 ячеек, остальное за «ещё» |
| Над сценой | 7 видов знаков: стрелка-улучшение, таймер процесса, «!», zZz, пузырь сбора… | То же | Здания говорят сами за себя |

## 2. Целевая схема нашего двора (утверждена заказчиком, круг 18)

```
┌──────────────────────────────────────────────┐
│ [Лорд: портрет·ник·Ур.+полоса·VIP]   [ресурсы: мясо дерево камень металл грибы │ЗОЛОТО│]
│ [Строить]                            [Командиры]                              │
│ [Тренировка]                         [Клан]                                   │
│ [Исследование]                       [Предметы]                               │
│                                      [Лавка]                                  │
│                 (3D-сцена двора)             [Почта]                          │
│                                              [лента хрониста]                 │
│        [Двор] [Отчёты]   ( КАРТА )   [Хроника] [Модули]                       │
└──────────────────────────────────────────────┘
```

- **Левый столбик** (под карточкой лорда): «Строить» (молот, костяная клетка 40) — вход в режим стройки;
  ниже очереди **Тренировка** (мечи) и **Исследование** (паутина). С этапа C в ячейках очередей появятся
  кольца прогресса и таймеры.
- **Правая колонка** (под ресурсами — правило заказчика «справа — уведомления и служебное»): **Командиры**
  (шлем), **Клан** (щит), **Предметы** (сумка), **Лавка** (прилавок), **Почта** (конверт). Иконки уникальны
  по всему HUD, повторов с нижним меню нет.
- **Ресурсы**: одна строка, прижата вправо, растёт влево; **золото** — последняя ячейка с золотой рамкой
  (премиум-валюта, аналог «камней» RoK). Формат K/M/B — миллиарды не ломают строку.
- **Нижний док** (5 ячеек, предел жанра): **Двор · Отчёты · КАРТА (центр, приподнятая) · Хроника · Модули**.
  Карта в центре — самое частое перемещение, как замок/глобус у RoK; служебное (Модули: настройки, аккаунт,
  диагностика) — по краю.
- **Украшения** (фонари, скамейки, колодцы, кусты, стога и т.п.) живут **только во вкладке
  «Украшения» режима строительства** (третья вкладка списка построек: экономика · военные · украшения) —
  игрок ставит их сам на свободные клетки сетки; сцена двора сама ничего не «приносит» (решение круга 21).
- **Ратуша** стоит дверью и окнами на восток, к воротам: крыльцо встречает дорожку из ворот (круг 21).

## 3. Что рисуем сейчас, а что придёт с системами

| Элемент | Сейчас | Этап C/D |
|---|---|---|
| Ресурсы + золото | нули (модуль двора не выдаёт) | живые значения, тап → «откуда взять» |
| Строить | панель-заглушка | список построек: экономика · военные · украшения |
| Тренировка/Исследование | панели-заглушки | очереди с таймерами, 4 вида войск / ветки науки |
| Командиры…Почта | панели-заглушки | системы этапа D |
| Знаки над зданиями | — | 7 видов из RoK-словаря (§1) |
| Лента хрониста | работает | + «ближайшие дела» (3 задания с прогрессом) |

Каждая правка HUD сверяется с этой схемой; отступления — только через заказчика.

## Панель строительства (этап C2, внедрено)

- Вкладки: «Экономика · Военные · Украшения» — как решено в к21; украшения ставит только игрок.
- Сверху экономической вкладки — широкая карточка «Ратуша · Ур. N — Улучшить до ур. N+1» с ценой.
- Карточки 3 в ряд: знак (SVG, тёплая палитра), имя, цена иконками; нехватка ресурса подсвечена.
- Замок: «🔒 Нужна Ратуша ур. N» — здание видно, но серое; открытие = уровень Ратуши (потом — территория).
- После выбора карточки панель закрывается, снизу плашка «{Имя} — тапни по свободной клетке · Отмена».
- Одна постановка на выбор: тап по клетке сразу шлёт команду и закрывает плашку.
