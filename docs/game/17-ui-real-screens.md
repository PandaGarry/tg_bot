## Ограничение и цель следующего прохода

- Архивные снимки 2017–2024 показывают структуру; для текущих деталей сильнее официальные функции/патч-ноты 2026, но они не заменяют свежие скриншоты текущего клиента.
- `BlueStacks` добавляет рамку эмулятора — её нужно исключать из измерений игрового viewport. Встроенные в игру событийнные иллюстрации, напротив, часть event-панели, но не базовой темы города.
- Для воспроизведения нужны отдельные состояния одной и той же системы: `idle → selected → details → action/confirm → result`, плюс disabled/loading/cooldown/empty/error; текущие статичные источники покрывают только часть цепочек.
- Неизвестные DPI, safe area и исходный screenshot resolution не переводить в пиксели/токены. Для следующего этапа записывать устройство/разрешение/версию, фиксировать raw frame и сверять касания/анимации в живом клиенте.
- Цель TDL — воспроизвести функциональную ясность и иерархию, а не копировать чужие логотипы, IP-арт или точный skin интерфейса.
