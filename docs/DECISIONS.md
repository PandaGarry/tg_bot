## 08–09.10.2026: оболочка двора

- Каркас оболочки утверждён заказчиком 09.10.2026 (этап 0 готов). (решено)
- Ландшафт зафиксирован по скриншотам iPhone 13. Ряд внизу: лента слева, нижнее меню справа от неё. Квесты скрыты, пока чат раскрыт. (решено)
- Портрет — отдельная проверка заказчиком. (открыто)
- Вырезы и полосы безопасной зоны: отступ = max(безопасная зона, 8 px); все отступы считаются от этой величины, не суммируются. (решено)
- Один макет для портрета и ландшафта: элементы привязаны к краям, размеры фиксированы. (решено)

**Нижнее меню и кнопки**
- Нижнее меню: Почта, Карта/Двор, Клан, Лавка, Меню. Подписи оставляем. Иконки для Почты и Меню — открыто. (решено; иконки — открыто)
- Центральная кнопка адаптивная: на дворе «Карта», на карте «Двор». (решено)
- «Хроника» убрана из нижней навигации. (решено)
- Остальные кнопки — заглушки с сообщением «ещё не реализовано», кроме строительства. (решено)
- Иконки квадратные, одного формата, не слишком реалистичные. Генерировать новые без просьбы не нужно. Временно — существующие иконки проекта. (решено)

**Правая панель**
- Переключатель «Актив» / «Ивент» — компактная строка, подписи сохраняются. (решено)
- «Актив»: Марш, Строительство, Исследование, Лечение. Иконки без ячеек, тонкая рамка. (решено)
- Подменю у кнопок «Актив» — нужны. Лимиты: строители 2, марши 5, исследования 2. (решено)
- Тренировка — кнопка с подменю по 4 видам войск (временные названия: ближний бой, дальний бой, конница, осадное оружие). (решено; названия — открыто)
- Лечение — не подменю: показывает раненых в лазаретах, которых можно вылечить. (решено)
- Ивенты вводим вместе с разработкой ивентов. (решено)
- Тени у иконок запрещены. (решено)

**Ресурсы и профиль**
- Ресурсы: иконка сверху, число снизу, без ячеек, короткие числа (k/M). Порядок: мясо · дерево · камень · металл · грибы · золото. Золото — отдельный чип справа. (решено)
- Рядом с числом — зелёный доход в час, например «+15». Пока заглушка. (решено)
- Профиль: уровень персонажа у аватарки, VIP под именем, сила. Уровня Цитадели в профиле не показываем. Данных пока нет: заглушки «—» или примеры с пометкой. (решено)

**Золото**
- Золото — премиум-валюта, вне стоимости построек. Выносится отдельным шагом. (решено)

**Квесты**
- Квесты — отдельный блок над чатом. Показываем 1–3 последних и активный, полупрозрачные, с прогрессом (например «0/100») и многоточием. (решено)

**Чат**
- Чат — не кнопка дока, а лента слева. По нажатию выезжает панель 50–60% интерфейса. (решено)
- Свёрнутая лента показывает 3–5 последних сообщений вкладки, на которой остановился игрок. Позиция вкладки сохраняется. (решено)
- Вкладки в порядке: Кор-во, Мир, Клан, ЛС, в конце ⋯ (настройки, заглушка). (решено)
- Теги источника: в свёрнутой ленте — у каждого сообщения. «Кор-во» — межмировой чат: тег только номер мира (№N, без слова «Мир»). «Мир» — чат внутри королевства: тег «Мир» без номера. «Клан», «ЛС» — подпись канала. (решено)
- В раскрытом чате теги только у «Кор-во». (решено)
- Ярлык непрочитанного — мелкий (число), в правом верхнем углу. Универсальный компонент. Сбрасывается при открытии канала. (решено)
- Тап вне раскрытого чата закрывает его, крестик остаётся. Эмодзи-панель закрывается после отправки. (решено)
- Поле ввода с кнопкой «Отправить» и эмодзи. (решено)
- Ширина свёрнутой ленты — 190 px. (решено)

**Бегущая строка**
