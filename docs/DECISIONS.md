## 13.10.2026: оформление входа и регистрации

- Стиль окон входа и регистрации: смешанный — тёмная палитра и лёгкая готика из концепции, но без плотного «мрака»: меньше теней и фактур, больше воздуха и контраста текста. Тени запрещены. (решено, заказчик 13.10)
- Шрифт интерфейса (кнопки, поля, подписи, ошибки): Manrope. Шрифт заголовков: Unbounded. Текст превью и подсказок — Cormorant Garamond (решено 12.10). Все три — открытые лицензии OFL. (решено, заказчик 13.10)
- Набор компонентов входа — собственный, на Tailwind: кнопка, поле, подсказка ошибки, карточка, переключатель языка. Адаптивен от 360 px; поля и кнопки не ниже 44 px. Внешнюю UI-библиотеку не подключаем без отдельного решения. (предложено; основание — стек проекта)
- Кнопки Google ID и Яндекс ID показываются сейчас. Вход через провайдера работает, когда заказчик даст Client ID и секрет для каждого сервиса; до этого кнопка ведёт к понятному сообщению «Вход через {provider} пока не подключён». Apple ID — позже. (решено, заказчик 13.10)
- Серверные изменения для сессий разрешены (решено 12.10); механизм токена — в `design/onboarding.md` 1a.
