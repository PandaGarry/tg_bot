# Документация The Dead Lords

Это краткая точка входа в актуальную документацию TDL. Исторические спецификации и архивы могут содержать решения, которые позднее были заменены; при конфликте следовать актуальному журналу решений и продуктовой спецификации.

## Читать в первую очередь

1. [Оперативный план производства](../PROJECT_MASTER.md) — этапы, зависимости, gates и критерии перехода.
2. [Продуктовая цель и критерии приёмки](TDL_PRODUCT_VISION_AND_ACCEPTANCE.md) — стиль, платформы, vertical prototype и quality gates.
3. [Журнал решений](DECISIONS.md) — утверждённые решения владельца; новые записи сверху.
4. [Совместная работа Cloud / Arena.ai / ChatGPT](AI_COLLABORATION/README.md) — роли, очередь, handoff, ветки, PR и review.
5. [Текущее состояние и доказательства](AI_COLLABORATION/STATUS.md) — фактические SHA, CI, блокеры и следующий шаг.

## Правило

Код и тесты показывают, что реализовано. Документы показывают, что утверждено и что предстоит сделать. Не считать описание функции доказательством её реализации. Не использовать исторические файлы как источник текущих продуктовых решений без сверки с `DECISIONS.md`.
