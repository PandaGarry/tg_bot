# Журнал решений

Один источник правды о том, что решено. Новые решения — сверху, с датой. Если решение меняет документ, документ правится в том же коммите. Статусы: **решено** — обязательно к исполнению; **открыто** — ждёт заказчика; **отменено** — не действует, оставлено для истории.

## 09.10.2026

- **Термины.** Двор — территория замка и экран управления. Цитадель — главное здание внутри двора. Слово «Двор» как название здания не используется. (решено)
- **Склад — единственное хранилище.** Погреб не вводим. Отдельное хранилище грибов не делаем. Предел грибов на складе — открыто, решим при таблице зданий. (решено; предел — открыто)
- **Исследовательское здание называется «Академия».** Название «Паутина» отменено: это образ расстановки иконок исследований, не название здания. (решено)
- **Ограждение вокруг города называется «Стена».** Название «Частокол» отменено. Это оборонительное сооружение, защищающее город. (решено)
- **Сила здания** — отдельная таблица, обсуждаем при введении зданий в игру. (открыто)
- **Таблица зданий — следующий шаг.** Набор зданий и названия фиксируем таблицей, потом формулы, потом баланс. Разработка не начинается до утверждения таблицы. (решено)
- **`docs/game/09-numbers.md` делится на три документа:** каталог зданий, формулы, баланс (армия, лорд, карта, бонусы). Баланс переносится, когда его системы начнут проектироваться. (решено; разделение — следующий шаг)
- **Централизация документации.** Один журнал решений (этот файл), один документ на тему, статус каждого документа — в индексе `docs/game/README.md`. Старое и отменённое — в архив, не в основной поток. (решено; перенос — отдельный шаг)
