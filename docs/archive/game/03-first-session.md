# Первая сессия

Только первый запуск на устройстве. Повторный вход слайды не крутит. Пропуск есть со второго слайда. Текст слайдов остаётся в хронике.

Порядок:

1. Слайды.
2. Создание лорда.
3. Замок и обучение.
4. Свобода. Дальше классические механики.

## Создание лорда

Один экран. Не конструктор лица.

Цвет кожи, причёска и шрамы ползунками не делаем. На карте это не читается, арт раздувает, замок отодвигает. Узнают по имени, портрету и знамени.

1. Имя. 2–18 знаков. Буквы, цифры, пробел, дефис.
2. Портрет. Восемь готовых голов. Любая голова подходит любому типу.
3. Знамя. Шесть знаков и восемь цветов. Знаки: череп, колокол, зуб, рука, башня, гриб.
4. Тип. Три карточки, одна строка бонуса.

| Тип | RU | EN | Бонус | Карточка |
|---|---|---|---|---|
| flesh | Плоть | Flesh | Замок чуть лучше держит удар | Тяжёлый, шитый |
| bone | Кость | Bone | Войско учится чуть быстрее | Сухой, в старой броне |
| spore | Спора | Spore | Ферма чуть щедрее на грибы | Бледный, тихий |

Кнопка: «Занять двор» / «Take the court».

Короткое имя — кнопка пишет, чего не хватает. Без шутки.

## Обучение

Двор. Хронист один раз:

«Живые уже у частокола. Их много. Пирогов нет. Частокол пока держит. Дальше это ваша работа.»

Один шаг — одна подсветка.

1. Ресурсы. Нажать на дерево. Оно копится само, у склада есть край. Мясо копится так же, из загона.
2. Улучшить лесопилку или частокол. Увидеть таймер.
3. Открыть ферму. Увидеть, что грибы растит она. Мясо растит загон, не ферма.
4. Открыть казарму. Обучить маленький отряд. Увидеть тир.
5. Открыть командира марша. Увидеть, что отряд без командира не выходит.
6. Открыть карту у двора. Увидеть ополченцев. Бить их в обучении не обязательно.
7. Закрыть фразой: «Дальше двор ваш. Живые никуда не делись. Соседи тоже.»

Если в обучении ткнуть в закрытый центр, хронист говорит: «Столица за печатями. Неделя выгоды начнётся не сегодня.» / «The capital is sealed. The week of advantage does not start today.»

Поражение в обучении невозможно.
