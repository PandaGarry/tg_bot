# TDL-ENV-001 — проверить рабочую среду Arena.ai

- **Статус:** READY
- **Владелец:** Arena.ai
- **Координатор:** ChatGPT
- **Дата:** 12.11.2026
- **База для чтения:** PR #9, ветка `arena/8885a9e3-tg-bot`; перед запуском сверить актуальный HEAD в GitHub.
- **Цель:** подтвердить, какие практические проверки Arena.ai действительно может выполнять для TDL.

## Scope — только проверка среды

1. Прочитать `AGENTS.md`, `docs/AI_COLLABORATION/AGENT_START_HERE.md`, `docs/AI_COLLABORATION/README.md`, `docs/AI_COLLABORATION/STATUS.md` и `PROJECT_MASTER.md`.
2. Получить актуальную ветку/commit SHA. Не использовать старую копию без обновления.
3. Установить/проверить наличие Node.js, pnpm, браузера Chromium/Chrome, PostgreSQL и возможность запускать локальный web server.
4. Выполнить установку зависимостей и доступные проверки согласно `AGENTS.md`; если среда не поддерживает какую-либо команду — записать точную ошибку и ограничение.
5. Запустить проект штатным способом, пройти короткий smoke test: стартовый экран/auth (если требуется тестовый аккаунт), загрузка мира/двора, базовая навигация. Не создавать реальные аккаунты/платежи и не использовать production credentials.
6. Сделать фактические screenshots из браузера: desktop viewport и узкий mobile viewport. На каждом указать commit SHA, viewport и шаг сценария. Если проект не запускается, приложить скрин ошибки/логи и причину.
7. Проверить Godot отдельно: версия/возможность установки, доступность headless запусков и web export templates. Не менять основной проект, не устанавливать движок в production dependencies и не начинать перенос игры.

## Запреты

- Не менять код, документацию или зависимости проекта.
- Не делать commit/push и не создавать PR по этой задаче.
- Не менять БД вне локальной тестовой среды.
- Не выдавать макет или скриншот редактора за runtime игры.
- Проверка Godot — только capability check, не выбор движка.
