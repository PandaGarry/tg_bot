# TDL-3D-001 — сравнение вариантов 3D-технологии

- **Статус:** READY
- **Владелец задачи:** ChatGPT
- **Практическая проверка:** Arena.ai — отдельным handoff после предварительного анализа и согласования владельцем
- **Дата обновления:** 12.11.2026
- **База документации:** актуальный `main`; получить HEAD через GitHub перед началом.
- **База сравнения:** изучить обе стороны: `main` (интегрированная React Three Fiber + Three.js сцена) и актуальный HEAD PR #9 (предлагаемый PixiJS rewrite, удаляющий R3F/Three). PR #9 не слит, его код не считать частью `main`.
- **Связанные документы:** `PROJECT_MASTER.md`, `docs/TDL_PRODUCT_VISION_AND_ACCEPTANCE.md`, `docs/DECISIONS.md`, `docs/AI_COLLABORATION/README.md`.

## Цель

Дать владельцу проекта доказательное сравнение технических путей к полноценной 3D изометрической стратегии для mobile + browser/PC, не меняя production-клиент.

## Входит

- Изучить текущую 3D-сцену main (`apps/client/src/court/CourtScene.tsx`, `apps/court3d/`), proposed PixiJS rewrite из PR #9 (`apps/client/src/game/court/`), React HUD, server-authoritative state и asset pipeline.
- Сравнить минимум три варианта:
  1. продолжить и модернизировать существующую интеграцию React Three Fiber + Three.js;
  2. рассмотреть прямой Three.js и Babylon.js как web-native альтернативы/варианты архитектуры;
  3. рассмотреть Godot с Web export как отдельный движковый кандидат;
  4. оценить PixiJS rewrite PR #9 только как 2D/гибридный путь и явно указать, соответствует ли он принятому full-3D требованию.
- Оценить mobile browser/touch, desktop browser, загрузку, FPS/frame-time, память, инструменты, импорт glTF/PBR, освещение, тени, LOD, UI overlay, интеграцию с текущим backend, размер сборки, CI и сложность поддержки.
- Проверить актуальные официальные документы и ограничения; дать ссылки на первоисточники и дату проверки.
- Разделить подтверждённые факты документации, анализ кода, инженерные оценки и непроверенные предположения.
- Предложить один и тот же минимальный benchmark-сценарий для честного сравнения.

## Не входит

- Не менять основной клиент и production зависимости.
- Не создавать массовую миграцию или удалять PixiJS.
- Не объявлять Godot/Three.js/Babylon.js утверждённым движком.
- Не менять протокол, сервер, БД, экономику или auth.
- Не считать красивый рендер достаточным доказательством работоспособности.
