# Агенту Cloud / Arena.ai: начать отсюда

Вы подключаетесь к общей разработке The Dead Lords (TDL). Ваша задача — продолжить существующую игру, а не создать отдельную игру или переписать проект по собственному усмотрению.

## Обязательный порядок

1. Откройте `AGENTS.md`, затем `docs/AI_COLLABORATION/README.md`, `docs/AI_COLLABORATION/STATUS.md`, `PROJECT_MASTER.md`, `docs/DECISIONS.md` и `docs/TDL_PRODUCT_VISION_AND_ACCEPTANCE.md`.
2. Сверьте текущий HEAD, активные PR и статус CI. Не работайте по старому SHA и не считайте незлитый PR частью `main`.
3. Найдите назначенную задачу в `docs/AI_COLLABORATION/QUEUE.md` и прочитайте её handoff. Если задачи нет — не начинайте кодить: предложите независимый аудит или запросите назначение.
4. Подтвердите в чате владельцу, что прочитали, какой SHA используете, какой scope поняли и какие файлы собираетесь менять.
5. Создайте собственную ветку от согласованной базы. Не работайте одновременно с другим агентом в одних файлах.
6. Выполняйте только scope задачи. Не меняйте целевой движок, серверный контракт, экономику или схему БД по собственной инициативе.
7. Передайте результат PR и заполненным handoff с тестами и доказательствами.

## Специализация по умолчанию

- **Cloud:** независимый технический/визуальный аудит, анализ вариантов, поиск противоречий, review чужих PR. Не переписывайте файлы только ради собственного стиля.
- **Arena.ai:** воспроизводимый запуск, браузерные walkthrough, проверка сцен и прототипов, реальные скриншоты, технические эксперименты в изолированной ветке/каталоге. Эксперимент с Godot не означает утверждение Godot как движка игры.
- **ChatGPT:** координация задач, архитектурная сверка, интеграция, review, контроль статуса и документации.

## Формат ответа при передаче

Сообщите:
- task ID и базовый commit SHA;
- что фактически изменено;
- commit/PR;
- точные команды тестов и их результат;
- browser/device steps, viewport и скриншоты, если задача визуальная;
- что не удалось проверить;
- известные риски и следующий шаг.

**Нельзя писать «готово», если есть только концепт, план, скриншот макета или непроверенный код.**
