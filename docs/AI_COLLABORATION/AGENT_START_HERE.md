# Arena.ai — начать отсюда

Ты подключаешься к практической части разработки The Dead Lords (TDL). Задача — проверять и развивать существующую игру, а не создавать отдельную игру или переписывать проект по собственному усмотрению.

## Обязательный порядок

1. Открой `AGENTS.md`, затем `docs/AI_COLLABORATION/README.md`, `docs/AI_COLLABORATION/STATUS.md`, `PROJECT_MASTER.md`, `docs/DECISIONS.md` и `docs/TDL_PRODUCT_VISION_AND_ACCEPTANCE.md`.
2. Сверь текущий HEAD, активные PR и статус CI. Не работай по старому SHA и не считай незлитый PR частью `main`.
3. Найди назначенную задачу в `docs/AI_COLLABORATION/QUEUE.md` и прочитай её handoff.
4. Подтверди владельцу, какой SHA используешь, какой scope понял и какие файлы собираешься менять.
5. Создай собственную ветку от согласованной базы. Не работай одновременно с ChatGPT в одних файлах.
6. Выполняй только scope задачи. Не меняй целевой движок, серверный контракт, экономику или схему БД по собственной инициативе.
7. Передай результат с точными командами, exit codes, скриншотами и ограничениями. Кодовые изменения — только через отдельный PR.

## Твоя основная специализация

- Установка и запуск проекта в доступной среде.
- Browser walkthrough и проверка реального поведения.
- Проверка desktop и узкого mobile viewport.
- Реальные runtime screenshots и короткие видеозаписи, если доступны.
- Проверка Godot/Web export и изолированные технические эксперименты по отдельному разрешению.
- Независимая проверка результата, который ChatGPT подготовил по документации или коду.

Не нужно самостоятельно повторять большое исследование технологий, если это не указано в handoff. Не принимай за факт то, что нельзя воспроизвести.

## Формат отчёта

Сообщи:
- task ID и базовый commit SHA;
- что фактически изменено;
- commit/PR, если были изменения;
- точные команды тестов и их результат;
- browser/device steps, viewport и скриншоты, если задача визуальная;
- что не удалось проверить;
- известные риски и следующий шаг.

**Нельзя писать «готово», если есть только концепт, план, скриншот макета или непроверенный код.**
