### Key audit conclusions (Scope A)

1. **Zero production 3D/PBR assets exist:** Nothing in the repository can be directly loaded into a 3D glTF/PBR Citadel pipeline yet.
2. **Zero explicit license provenance exists:** No file carries a `LICENSE`, `NOTICE`, or commercial asset grant. In line with `TDL-ARCH-004` policy, **license is recorded as `unknown`** for every binary asset (including AI-generated art and un-attributed third-party captures), even where internal notes document how a file was generated or cropped.
3. **`apps/client/public/icons/` ships 2.60 MiB of unreferenced PNG bloat:** Exact static reference scanning shows **13 unused files** (`2,730,207 B`) in `apps/client/public/icons/`, led by `i-web.png` (`2,118,164 B`, `1408x768`) plus 12 legacy Circle-5 HUD sprites (`bag.png`, `banner.png`, `clan.png`, `hammer.png`, `helmet.png`, `mail.png`, `map.png`, `quill.png`, `scroll.png`, `shop.png`, `swords.png`, `web.png`). Vite copies all of `apps/client/public/` verbatim into `apps/client/dist/`.
4. **Provenance notes from `docs/game/24-court-3d.md` & `docs/game/ui/hud/README.md`:**
   - The 22 active `512x512` glossy icons in `apps/client/public/icons/` (`i-*.png`, `crown.png`, and the 6 resource icons) were generated from `docs/game/ui/icon-packs/glossy/` using a one-off Python/PIL transparency + bounding-box normalization script **not checked into the repo** (`docs/game/24-court-3d.md:548-563`).
