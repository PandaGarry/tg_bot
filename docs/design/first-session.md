# Первый запуск: превью, загрузка, вход

> Статус: **на обсуждении** · Обновлено: 12.10.2026
> Решения: `DECISIONS.md` (блок 12.10, «вступление и порядок входа») · Связано: `design/onboarding.md` (вход, создание лорда), `canon/lore.md` (история), `canon/tone.md` (тон)
> Открыто: список в конце

Превью показывается один раз, при первом запуске на устройстве. Повторный вход его не крутит. Полный порядок экранов — `onboarding.md`, раздел 1.

## 1. Порядок

- **Первый запуск:** превью → экран загрузки → вход или регистрация → создание лорда → двор → обучение.
- **Повторный вход с действующей сессией:** экран загрузки → двор.
- **Повторный вход без сессии:** экран загрузки → вход → двор.

Решено 12.10 (заказчик). Загрузка идёт после превью и до входа.

## 2. Превью (кинематографичное)

Около 90 секунд, 10 кадров. Тон и история — `canon/lore.md`, раздел «Камень» — «Живые теперь».

Правила:
- **Переход между кадрами — по окончании озвучки**, не по таймеру. (решено 12.10)
- **«Далее»** — переход к следующему кадру раньше озвучки. (решено 12.10)
- **«Пропустить»** — сразу к загрузке, доступен со второго кадра. (решено)
- **Озвучка** — русская и английская, записана заранее. В браузере грузится один файл — по языку. (решено 12.10; выбор голосов — открыто)
- **Повтор** — в настройках. (предложено)
- Текст крупный и короткий, одна музыкальная тема, игровых кнопок на экране нет.
- Телефон: кадр вертикальный, текст крупнее. Если в системе включено «уменьшить анимацию», кадры статичные, переходы — плавные затемнения. (предложено)

- Содержание: подсказки о мире и игре, полоса прогресса. Тексты подсказок — открыто.
