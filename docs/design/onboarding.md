# Вход, превью, создание лорда

> Статус: **на обсуждении** · Обновлено: 12.10.2026
> Решения: `DECISIONS.md` (блоки 11.10, «платформа», «вход, превью, создание лорда», 12.10 «вступление и порядок входа», «вход и язык») · Открыто: список в конце
> Связано: `design/first-session.md` (слайды, обучение), `canon/lore.md`, `canon/tone.md`, `design/style.md` (стиль — отдельно)

Этот документ — путь от первого запуска до двора: превью, вход или регистрация, создание лорда, выход в игру. Слайды и обучение описаны в `first-session.md` и здесь не повторяются.

## 1. Порядок экранов

1. **Превью** — кинематографичное, 10 кадров, около 90 секунд. Только первый запуск (решено 12.10, `first-session.md`).
2. **Экран загрузки** — анимированный, после превью и до входа (решено 12.10).
3. **Вход или регистрация** — способы ниже.
4. **Создание лорда** — только для нового аккаунта, после входа. Персонаж заводится отдельно от логина (как сейчас в `shell.register.note`).
5. **Занять двор** — переход в игру, первое обучение (`first-session.md`, раздел «Обучение»).

Вернувшийся игрок (решено 12.10):
- с действующей сессией: загрузка → двор, превью не показываем;
- без сессии: загрузка → вход → двор.

## 1a. Запоминание входа

Решено 12.10 (заказчик): после перезагрузки страницы и после долгого перерыва игрок заходит без логина и пароля, пока сессия действует.

- Срок сессии, число устройств, кнопка «Выйти», поведение после смены пароля — открыто.
- Механизм (долгоживущий токен входа на устройстве, продление при активности) — предложено, не подтверждено. Серверная часть (сессии) меняется только с разрешения заказчика; до этого решения код входа не трогаем.
- Вход через Google и Яндекс ID тоже запоминается по этим же правилам (предложено).

## 1b. Язык

- Язык определяется автоматически при первом запуске: русский, если язык браузера или устройства русский, иначе английский. (решено 12.10, пожелание заказчика; правило для неподдерживаемых языков — предложено)
- Выбор в настройках сохраняется и важнее автоопределения. (предложено)
- Превью, загрузка, вход и весь интерфейс — на выбранном языке. Озвучка превью — один файл на язык (`first-session.md`).

## 2. Способы входа

| Способ | Статус | Заметка |
|---|---|---|
| Логин или почта + пароль | есть в клиенте | основа |
| Apple ID | продакшен, позже (11.10) | заранее не реализуем; требует аккаунта разработчика Apple |
| Google ID | реализуем сейчас (11.10) | условия и доступ — проверить до кода |
| Яндекс ID | реализуем сейчас (11.10) | условия и доступ — проверить до кода |

Правила для всех способов:
- Один аккаунт — один вход. Если почта уже есть у другого способа, предлагаем связать, а не заводить второй аккаунт (предложено).
- Почта от провайдера не пришла — просим указать вручную (предложено).
- Логин (аккаунт) и имя лорда — разные вещи (как сейчас). Логин выбирается при регистрации через логин и пароль; у провайдерных входов логин создаётся автоматически и меняется в настройках (предложено).

## 3. Создание лорда (доработка)

Сейчас есть основа: имя, портрет, знамя, знак, цвет, тип. Внешний вид не готов. Что нужно:

- **Портреты.** Набор голов (сейчас восемь в описании). Число и стиль — открыто. Художественный стиль — `design/style.md`.
- **Знамя.** Фон, знак, цвет. Предпросмотр знамени на экране. Знаки: череп, колокол, зуб, рука, башня, гриб (как в `first-session.md`, подтвердить).
- **Описание.** Короткая биография лорда (строка-две) или выбор из готовых фраз. Открыто: свободный текст или выбор.
- **Тип.** Три карточки: Плоть, Кость, Спора. Бонусы и состав — открыто (см. `DECISIONS.md`, «типы лорда»).
- **Итог.** Экран-карточка лорда перед кнопкой «Занять двор»: портрет, знамя, имя, тип, описание.
- Имя лорда: 2–18 знаков, буквы, цифры, пробел, дефис. Проверка уникальности — открыто (в мире или глобально).

## 4. Сообщения (предложенные тексты)

Все сообщения — спокойные и точные. Без шуток на экране ошибки (`canon/tone.md`: «Шутка на экране поражения» — нельзя).

| Ситуация | Текст (RU, предложено) | Текст (EN, предложено) |
|---|---|---|
| Логин занят | Логин занят. Выберите другой. | This login is taken. Choose another. |
| Логин не подходит | Логин: 3–24 знака — латиница, цифры, точка, дефис, подчёркивание. | Login: 3–24 characters — Latin letters, digits, dot, hyphen, underscore. |
| Почта занята | На эту почту уже заведён вход. Войти? | This email already has an account. Sign in? |
| Почта неверна | Почта написана неверно. | This email address is not valid. |
| Пароль короткий | Пароль: не короче 8 знаков. | Password: at least 8 characters. |
| Пароли не совпадают | Пароли не совпадают. | Passwords do not match. |
| Неверный логин или пароль | Логин или пароль не подходят. | Login or password is incorrect. |
| Аккаунта нет | Такого аккаунта нет. Проверьте логин или зарегистрируйтесь. | No account with these details. Check the login or register. |
| Имя лорда занято | Имя лорда уже занято. Выберите другое. | This lord name is already taken. Choose another. |
| Имя лорда не подходит | Имя: 2–18 знаков — буквы, цифры, пробел, дефис. | Name: 2–18 characters — letters, digits, space, hyphen. |
| Нет согласия с правилами | Без согласия с правилами аккаунт не заводится. | Account creation requires agreeing to the rules. |
| Провайдер не ответил | Вход через {provider} не удался. Попробуйте другой способ. | Sign-in with {provider} failed. Try another method. |
| Провайдер без почты | Провайдер не передал почту. Укажите её вручную. | The provider did not share an email. Enter it manually. |
| Сессия истекла | Сессия истекла. Войдите снова. | Your session has expired. Sign in again. |
| Много попыток | Слишком много попыток. Подождите немного. | Too many attempts. Please wait a moment. |
| Нет связи | Нет связи с миром. Попробуйте ещё раз. | No connection to the world. Try again. |
| Вход закрыт | Вход временно закрыт. | Sign-in is temporarily closed. |

Тексты появляются под полем, рядом с ним. Общие сообщения — сверху формы. Тексты ведутся в `i18n` (ru и en), `pnpm check` проверяет полноту.
